How I work

From a Figma file to a live page

  1. Read the designCheck every breakpoint and state in Figma and ask the designer about gaps before coding.
  2. Build the sectionsReusable blocks in BEM, so the next course page is assembled, not rewritten.
  3. Test on real devicesCompare against the mockup and fix browser and device differences.
  4. Ship with the teamHand off to the product manager and backend through Jira and Git.
